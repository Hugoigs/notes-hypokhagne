
Définition de sujet : 3 sens possibles
-> Sujet politique 
-> Sujet grammatical 
-> Sujet philosophique 


### Sujet politique : la question de la domination 

| **Mot** | **Origine**        | **Signification**                      |
| ------- | ------------------ | -------------------------------------- |
| Sujet   | Latin: _subjectum_ | _Ce_ qui est en dessous ou sous-jacent |
L’assujettissement politique peut être légal, comme dans un État de droit, ou tyrannique, réduisant les sujets à la servitude. La philosophie peut étudier le sujet politique, indépendamment de l’usage technique du terme.

###  Le sujet grammatical : la chose et le moi 

|                              |                                                      |                                             |
| ---------------------------- | ---------------------------------------------------- | ------------------------------------------- |
| **Catégorie**                | **Description**                                      | **Exemples**                                |
| Sujet d’un verbe d’action    | L’entité qui accomplit l’action.                     | Le marteau frappe l’enclume                 |
| Sujet d’un énoncé attributif | L’entité qui est décrite par le verbe « être ».      | Socrate est philosophe, mortel, barbu, etc. |
| Sujet implicite              | Le sujet est compris mais pas exprimé explicitement. | Pas de chance!                              |

L’usage du terme « sujet » en grammaire, bien que banal, a des conséquences philosophiques importantes, car il influence notre conception des choses, des acteurs et de leurs actions.
### La notion philosophique du sujet :substance et subjectivité


| **Terme** | **Description**                                                        | **Exemple**                                        |
| --------- | ---------------------------------------------------------------------- | -------------------------------------------------- |
| Sujet     | Ce qui subsiste toujours dans quelque chose et constitue sa substance. | Socrate                                            |
| Accident  | Propriété possible d’une substance, qui n’affecte pas son essence.     | Assis, debout, dormant, philosophant, jeune, vieux |
