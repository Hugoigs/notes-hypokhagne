# I . La communication : une activité sociale ordinaire


## 1. Les processus de communication

__La communication, avant d'être considérée comme un ensemble d'activités spécifiques généralement liées à la médiation de technique, peut être envisagée comme une pratique sociale banale mettant en relation divers individus au sein d'une même société__. 

==Norbert Wiener er Claude Shannon== :
-> Analyse de la communication interpersonnelle 
=> Proposent un schéma linéaire de la transmission de l'information d'un émetteur à destination d'un récepteur
![[Capture d’écran 2026-02-17 à 10.38.45.webp]]
Explication : 
- **Source d’information** : produit le message (ex. : une personne qui veut parler).
- **Émetteur** : encode le message en signal (voix, signal électrique).
- **Canal** : support de transmission (air, téléphone, radio…).
- **Bruit** : tout ce qui perturbe la transmission (parasites sonores, mauvaise connexion).
- **Récepteur** : décode le signal.
- **Destinataire** : reçoit et comprend le message.
=> L’objectif est que le message reçu soit le plus fidèle possible au message envoyé.
-> Dans ce cadre, le cheminement de la communication doit éviter les perturbations (les "bruits) susceptibles de nuire la transmission  du message. 

==Critiques== : 
-> Ecole de Palo Alto / "collège invisible"
-> Pointe la complexité  des processus de communication qui ne peut se résumer en un schéma linéaire : 
- Insistent sur le rôle du récepteur que de l'émetteur -> dans la mesure où le premier  est toujours conduit à interpréter les messages qui lui sont adressées. 
- Communication n'est pas que uniquement verbal-> les gestes (kinésique) + espace interpersonnel (proxémique).

Anthropologue ==Edward T.Hall== : ___"Proxemies",Current Anthropology___ 1968
-> Se penche sur les codes de la communication interculturelle ![[Capture d’écran 2026-02-17 à 11.09.40.webp]]
=>  Interaction visuelle différente entre les Américaines et les Arabes 
- Arabes : Interaction plus intense, engagement est direct -> regardent leur interlocuteur fixement. Tendance à rester dans à l'intérieur de la bulle olfactive de leur interlocuteur. 
=/= 
- Américains : Inverse, restent à l'écart 

==Gregory Bateson== : 
-> Conception "orchestrale" de la communication 
=> Permet au locuteur de restreindre les différentes significations d'un terme, d'un comportement ou d'une situation. 
==Winkin== : Donner quelques propriétés
- C -> envisagée comme une activité sociale requérant la maitrise d'un code culturel 
- aucun acte de C est univoque -> signification dépend du contexte d'interaction 
- C -> un élément consubstantiel de la vie sociale qui ne peut être interprété uniquement en termes "d'échec" ou de "succès"
==> Image de l'orchestre signifie que les différents membres d'une culture apportent leur contribution, chacun à leur manière, au processus de communication.

## 2. La communication en actes 

__Le sociologue canadien Erving Goffman est d'une certaine façon un membre à part du "collège invisible"__

==Erving Goffman== : 
___Communication Conduct in a Island Community___ 1953 
-> Etude sur les relations quotidiennes interpersonnelles -> peuple insulaire 
- Habitants de Baltasound (île de l'archipel des Shetland en Grande-Bretagne)
=> Il s'interroge sur les relations de face-à-face + l'entrée en relation avec autrui, y compris sur les modes de gestions du silence.

___La mise en scène de la vie quotidienne (1959 et 1971)___
-> Métaphore dramaturgique => Rendre compte des stratégies de présentation de soi mises en oeuvres par les individus -> notamment dans les relations publiques 

___Rites d'interaction___ (1963)
-> Porte son attention aux comportements codifiés de la vie sociale qui ont pour finalité d'éviter les issues malheureuses des interactions. 

___Comment se conduire dans les lieux publics___ (1963) + ___Façons de parler___ (1981) 
-> Intérêt pour les ==engagements== (toute action sociale impliquant la définition de la personne vis-à-vis d'autrui) dont doivent faire preuve les individus dans la vie sociale . 
Mais les individus disposent de ==pare-enagement== -> autorisant dans certaines circonstances de s'abstraire d'une interaction. 
![[Capture d’écran 2026-02-17 à 11.46.04.webp]]
-> Existence des pare-engagements : 
- Femme de la société européenne -> plus d'éventails / masques pour dissimuler qu'elles rougissent ou manquent de rougir 
- Maintenant : les mains -> cacher les yeux // bâillement  
==> Eventail et journal sont remplacés par les mains. 

Intérêts de Gauffman -> souligner que l'issue de l'interaction n'est jamais garantie. En effet, les actes de communications peuvent faire l'objet de multiples interprétations orientant, à leur tour, les comportements + induisant de nouveaux messages.
