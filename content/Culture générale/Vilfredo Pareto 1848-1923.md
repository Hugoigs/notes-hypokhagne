__L'analyse de la consommation et de l'échange__

Dans son ouvrage précédent déjà _Cours d'économie politique_ 1896-1897
-> analyse la nature du rapport entre les choses + la satisfaction des besoins 
-> Distinction entre : ==utilité== et ==l'ophélimité== 
- Un rapport de convenance entre l'individu et la chose (plus objectif de l'utilité)
- Un rapport subjectif de convenance sans inquiéter de savoir si la chose satisfait un besoin légitime ou non, si elle est utile ou inutile (connotation morale)

Mais Pareto dans son oeuvre -> abandonne -> l'ophélimité => être objectif 
Pour les néoclassiques => Ce que un bien apportait à l'individu = son utilité comme une quantité mesurable 
-> Mais démarche novatrice paretienne -> ne plus raisonner avec un bien mais avec ==2 biens== supposées complémentaires (un peu plus de A mais moins de B ou inverse) 
-> Raisonnement plus sur une quantité ophélimité (imaginaire) => Une quantité  de biens réelles. -> Une base objective -> pour construire des schémas rigoureux 

Conséquences de cette novation théoriques, 2 principales : 
- Offre des ouvertures -> l'analyse de l'équilibre d'un agent seul ainsi que de l'échange entre agents => assurant "efficacement" à chacun le maximum d'ophélimité. 
- Impossibilité de toute comparaison temporelle des utilités => rechercher un critère pour déterminer le moment où le changement -> une amélioration et savoir quand l'optimum est atteint. 
-> Il démontre que l'optimum de consommation d'un agent, par redistribution des ressources, sans diminuer la consommation d'un autre agent => une situation qualifiée d'efficace ou d'optimal pour Pareto 

__L'analyse de l'équilibre général et du bien être__ 

Pour Pareto ==l'équilibre économique== -> notion transposé de la physique. 
-> Thèse "l'équilibre des corps solides " = le physicien a influencé l'économique 
Cette équilibre-> est stable en principe => cependant à priori ne possède pas ce caractère
-> Pour avoir un équilibre stable -> une faible modification intervenant => l'équilibre tende à se rétablir par lui même

Quelles sont les forces qui, en se compensant, établissent cet équilibre? 
-> C'est l'opposition entre goûts et obstacles -> naît l'équilibre 
- Si l'homme -> pas de désirs -> éprouve aucun besoin -> aucun goût => pas d'activité économique. 
=> C'est parce que l'homme ont des goûts -> et la satisfaction de ces goûts se heurte à des obstacles

Mais le problème économique -> 2 raisons : 
- Les goûts des hommes -> forts nombreux -> pour les satisfaire => ils disposent de solutions fort complexes + une infinité de choix à faire => Multiplication des combinaisons possibles 
-> Compliquer de savoir comment le sujet économique se décide et pour laquelle de toutes les combinaisons possibles il va opter. 
- Problème pas que sur un seul mais pour un ensemble d'individu => les goûts des uns peuvent constituer un obstacle pour la réalisation des goûts des autres. 
-> L'individu qui veut satisfaire ses goûts entre en compétition avec les autres -> pour obtenir les biens économiques nécessaires 
=> Se demande comment peut être atteint -> à partir de cette compétition entre les individus-> le max d'ophémilité pour l'ensemble. 

Pareto -> au delà de l'équilibre => la ==recherche de l'optimum== (le max de l'ophémilité)
Critère : tout changement qui ne nuit à aucun sujet et qui améliore la situation de certains autres constitue une amélioration dans l'ensemble= ==le critère de Pareto== 

Après avoir étudié l'équilibre + monopole => question suivante :
==l'équilibre correspond-il à un maximum d'ophémilité pour la collectivité tout entière ?== 
Réponse : 
Les antagonismes économiques -> naissent du fait que l'intérêt de certaines personnes => mes conduit à établir un équilibre en un point qui ne correspond pas au maximum d'ophémilité = optimum, pour la société française
